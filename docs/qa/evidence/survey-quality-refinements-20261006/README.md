# 质量阶段、规范适用与整改复查增量验证

日期：2026-10-06。此报告是 AI 工程测量、软件和产品视角的源码与桌面组件验证，针对私有工作树增量；不代表已安装包验收、真实工程师签认、规范合格认证或厂商互操作认证，也不改变已公开 0.5.2 的版本身份。

## 本轮完成的内容

- 质量流程的高级编辑支持检查策划、过程检查、最终检查和验收检查的开始及阶段结论。每项保留技术细则版本、检查范围和实际材料依据；界面没有新增批准或签字动作。
- 规范适用选择绑定明确的规范/版本、规则/版本、原规范来源、算法及成果类别。服务核对目录与规则摘要，客户端核对请求和返回内容；旧未绑定目录的声明仍可读取，不自动升级。
- 撤销旧适用声明后，可用同一规范、规则及成果类别的明确声明替代。旧记录及撤销链保留；被有效替代的旧撤销不再永久阻断后续检查。不能跨类别替代或重复替代。
- 整改后复查在同一成果总体、检查阶段和检查方式下安排新一轮，保留理由、此前计划及历次样本。新表保留既有首轮表及约束；每个前轮只有一个后轮，最多八轮，防止反复抽样直到出现满意结果。
- 读取复查时重算前轮抽样计划并复核连续关联；仅修补外层摘要无法掩盖计划内容篡改。客户端拒绝错误的前轮、总体、轮次和理由绑定。
- 后轮抽样仍可保存、读取和复核，但首轮声明关联评分入口只列首轮。现有评分引擎不被解释为已支持复查后的重新评分。
