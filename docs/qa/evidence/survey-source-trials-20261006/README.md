## 数值核验重点

两未知高程的独立交叉协方差核验采用 BM=10 m、P 初值 10.1 m、Q 初值 10.2 m，五条观测分别为 BM→P 0.100 m/σ=0.002 m、P→Q 0.1005 m/σ=0.003 m、BM→Q 0.1995 m/σ=0.004 m、BM→P 0.101 m/σ=0.002 m、P→Q 0.099 m/σ=0.003 m。

设计矩阵为 `[[1,0],[-1,1],[0,1],[1,0],[-1,1]]`。测试独立求出 2×2 法方程逆矩阵并逐项对比，确认保留非零交叉协方差，不能以逐点中误差平方替代完整协方差。未知参数 2、观测 5、自由度 3。测试同时检查 mm→m 单位转换、缺少初值时明确采用零初值、来源精确绑定、过期修订拒绝、原件/观测锚点/处理版本变化拒绝，以及正式成果不被改写。
