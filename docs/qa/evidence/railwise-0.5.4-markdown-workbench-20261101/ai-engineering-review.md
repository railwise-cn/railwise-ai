## Explicit scope and residual acceptance

- Markdown/MDX source remains authority. Supported visual core blocks can be edited; untouched blocks retain exact original bytes including CRLF and whitespace. Frontmatter, raw MDX/HTML, math, footnotes and Mermaid use protected source blocks in visual mode and remain editable in source/properties. This is not a claim that phase-two visual extensions or semantic Mermaid/math export are complete.
- Visual native edits across source-block boundaries are intentionally blocked. Noncanonical source spellings that cannot be mapped exactly yield no AI selection instead of guessing against repeated text. Clipboard HTML is inserted as plain text. These constraints need a clear source-mode escape path in product acceptance.
- Preview/export resource checks are local and passive by default. Raster hydration in the visual editor differs from the export helper's passive-SVG support; the final image fixture must be checked in all modes.
- The relationship view is a navigable edge list. No real-time collaboration, remote sharing or embedding network service is introduced.
- Search limits/skipped/truncated counts must be visible in the installed package. Shared source limits are 20,000 files, 2 MB per file, 64 MiB total and 200,000 scanned entries; BM25 additionally reports its 20,000-fragment / 2,000,000-token memory budget. Manifest caching is 1 second, visible search/semantics force refresh, unchanged file content is reused by metadata, and internal saves/rename invalidate. Source tests verify the former 160-file/720-fragment boundary and external refresh; packaged responsiveness still needs acceptance.
- Final acceptance must verify at least 20 open tabs, dirty close Save/Discard/Cancel, restored tabs, missing-file relocation, baseline conflicts, append-only restoration, anchored comments, selection/whole-document AI diff review, frontmatter errors, HTML/PDF/real OOXML DOCX, large-file write protection, light/dark Chinese/English narrow/wide UI, signature/notarization, ASAR/native dependencies and real updater round trip.
