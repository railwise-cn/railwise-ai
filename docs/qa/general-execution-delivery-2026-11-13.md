# 通用执行链与网页成果交付整改

本轮基于 0.5.6 的 Windows 实际使用反馈。验收原请求包含 BrowserSkill、招标信息采集、HTML 汇报和每日两次执行，须通过普通聊天入口完成。

## 兼容和默认状态迁移

- 现有 BrowserSkill 安装记录及用户文件继续保留。旧安装表示资料已安装，执行就绪还需检查 CLI、扩展、连接和站点授权。升级后从原条目补齐依赖。
- Skill 更新以带版本的目录清单同步到 Runtime，当前执行使用已捕获的版本。用户自定义文件与旧版本保留，移除遵守原包管理流程。
- 普通界面默认展示业务进展。命令、参数、哈希和日志可在执行详情中查看，持久执行记录继续保存。
- 审批恢复输入使用明确来源。历史 JSON 气泡只有在 SQLite 投递位点与原审批匹配时才转换为审批状态，原 JSONL 保留。
- 任务级写入授权仅作用于确认的路径和期限。工作区、Agent 或显式沙箱硬限制按执行时状态复核。应用任务成果拥有独立的输出目录。
- 旧计划的单时刻字段与无时区记录有兼容读取。每日时区、提前量和下次执行在界面与后台使用同一合同。应用运行期间执行，退出与休眠遵循持久恢复规则。

## 关闭条件

需完成精确 Windows 与 macOS 包验证、真实 BrowserSkill 采集、HTML 自动预览，以及同一精确包的一次实际到期执行。所有未验证项目在本文件中保持可见，发布记录引用最终源码和制品摘要。

官网页面由其他开发机维护。本轮代码范围为桌面、Runtime、依赖目录和验收资料。
