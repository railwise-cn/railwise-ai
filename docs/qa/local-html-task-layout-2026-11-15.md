# 本地 HTML 任务与任务侧栏整改

本记录对应 2026-11-15 用户在实际 0.5.7 候选包中提交的独立 HTML/SVG 动画。旧包源码为 `976e8de7698ba54721bc75eddd6f7ab70d1a54a0`。文件已保存并可在内置浏览器查看，但任务因“浏览器”关键词误进入网页来源验收，执行、验证、交付全部显示失败。该旧包的机器构建、安装和升级通过，不能替代此业务失败。

## 生产改动

- 共享来源意图区分本地创作与外部网页采集；混合采集任务仍要求真实来源。
- 有效文件写入保留执行步骤的完成证据，后续验证失败不抹去已完成工作。
- 受影响的已停止旧任务提供“重新检查成果”。服务端重新检查文件、成功写入回执、哈希、格式、明确文件名、最少数量、交付卡和最终回复；通过后才修正任务状态。不会重跑模型、重放外部动作或重置预算。
- 任务列表、搜索、工作区范围和状态筛选移到现有左侧栏。中间仅显示所选任务，完整要求和模板默认折叠，右侧按需展示成果。计数明确表示执行步骤。
- 停止的失败根任务可以显式追加执行时间，保持失败状态、历史、尝试次数、费用和权限；继续或重试为另一操作。完整任务族有在途执行时拒绝变更。

迁移及质量边界见[本地 HTML 验收迁移说明](../migrations/2026-11-15-local-html-source-acceptance.md)。结构和回执核验不代表动画造型、运动效果或画质已经经过人工审阅。

## 6219 精确 Windows 包发现的回归

源码 `6219fbca` 的六个 Quality job 和基础安装检查通过，但唯一完整 Windows 实装检查 `43696408487` 失败：等待用户处理的任务没有“暂停”入口，无法验证先暂停、完成安装与授权后仍保持暂停。失败发生在模型与浏览器执行前，Turn、模型请求和操作回执均为零。恢复全部非终态、未暂停任务的暂停入口，并增加 waiting_user、waiting_approval、stalled 三个状态的回归；不跳过原完整检查。该构建已请求取消，未作为可发布包。

只读审计还发现，原计划封存的 67 项工具不包含新加的正文读取工具。为保留旧授权边界，已把独立的、严格核验的加载响应读取折入原有 browser_get_html，作为整页 DOM 不完整时的内部读取通道，不增加工具名或扩展旧白名单，不修改原计划、授权封印或未知结果记录。加载响应仍标识自己的证据类型，不冒充完整 DOM。下一源码须重新构建并完成精确包验收。

追加修复的完整 Runtime 为 4,774 项通过／24 项跳过；845 个后端源码与测试文件和合并树逐字节一致。现有 get_html 的旧 67 项目录、真实 Grant 与独立响应证明已通过 Runtime 回归；完整 DOM 与显式子树保持原行为。暂停入口相关界面 35 项通过；源码新增三种等待状态，不把恢复行为简化为隐藏按钮。

同一计划等待项的重复失败保留通知标识，成功派发只解决对应 due/version 的等待；其它发生中的失败与原暂停任务保持不变。旧待办缺版本信息时必须由持久待派发记录核对，不根据模型文本或当前时间猜测。该修复不重建计划、不清空 outbox、不扩权限。上述仍为源码检查，下一精确安装包与实际任务结果另行记录。
