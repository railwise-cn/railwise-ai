# 本地 HTML 任务与任务侧栏整改

本记录对应 2026-11-15 用户在实际 0.5.7 候选包中提交的独立 HTML/SVG 动画。旧包源码为 `976e8de7698ba54721bc75eddd6f7ab70d1a54a0`。文件已保存并可在内置浏览器查看，但任务因“浏览器”关键词误进入网页来源验收，执行、验证、交付全部显示失败。该旧包的机器构建、安装和升级通过，不能替代此业务失败。

## 生产改动

- 共享来源意图区分本地创作与外部网页采集；混合采集任务仍要求真实来源。
- 有效文件写入保留执行步骤的完成证据，后续验证失败不抹去已完成工作。
- 受影响的已停止旧任务提供“重新检查成果”。服务端重新检查文件、成功写入回执、哈希、格式、明确文件名、最少数量、交付卡和最终回复；通过后才修正任务状态。不会重跑模型、重放外部动作或重置预算。
- 任务列表、搜索、工作区范围和状态筛选移到现有左侧栏。中间仅显示所选任务，完整要求和模板默认折叠，右侧按需展示成果。计数明确表示执行步骤。
- 停止的失败根任务可以显式追加执行时间，保持失败状态、历史、尝试次数、费用和权限；继续或重试为另一操作。完整任务族有在途执行时拒绝变更。

迁移及质量边界见[本地 HTML 验收迁移说明](../migrations/2026-11-15-local-html-source-acceptance.md)。结构和回执核验不代表动画造型、运动效果或画质已经经过人工审阅。

## 已确认的技能误匹配修复

新 SVG 执行的持久元数据另行暴露：独立本地动画错误载入了钉钉技能，注入约 24 KB 无关指令。对同一真实技能目录只读回放复现了该问题。匹配器现排除通用创建词和重复中文子串计分，平台命名空间须有相应的正向平台语境；本地创作不因“打开浏览器查看”自动载入浏览器采集技能。显式技能选择、原请求中的 `broswer-skill` 别名、真正的平台续答和工程术语仍保留，否定语句不能反向激活被禁止的技能。未修改任何用户技能文件、工具授权或凭据。

该修复的九个聚焦文件共 170 项通过，完整 Runtime 为 4,808 项通过／24 项跳过，类型和相关 lint 通过。完整检查对 832 个后端源码及测试文件绑定前后哈希，物理检查树与提交源码逐字节一致，未放宽超时或跳过原用例。同一目录回放中 SVG 请求不再注入无关技能，原招标请求仍首先选择显式 BrowserSkill。
