# RailWise AI 0.5.5

本版完善持续任务、工程文档交付和下载品牌统一。

- 任务保持连续：状态询问、中途补充、暂停和继续按任务处理，独立新任务保留原任务。普通界面以目标、进度、待办和成果为主，内部执行标识收纳到诊断中。
- 补充、人工待办、检查点和操作回执持久保存；重启时核验执行归属和未结操作，结果不明的副作用不会盲目重放。
- 任务工作台实时展示根任务、子任务汇总、成果和需处理事项；新增监测报告、招投标技术文件、研究报告三个交付模板。
- 文档候选提供来源、正文差异及接受/拒绝操作；提交前再次检查文件版本，发生冲突时保留双方内容和历史。
- 新安装包统一命名为 RailWise AI，官网使用新的下载命名空间；旧更新入口、安装身份、配置、插件及用户资料继续兼容。

下载文件：

- Apple Silicon：`RailWise-AI-0.5.5-mac-Apple-Silicon.dmg`
- Intel：`RailWise-AI-0.5.5-mac-Intel.dmg`
- Windows x64：`RailWise-AI-0.5.5-win-x64.exe`

兼容及已知限制：

- macOS 应用使用 Developer ID 签名并完成公证。Windows 本版未配置 Authenticode 证书，安装程序和可执行文件未签名。
- 长任务在应用 Runtime 存活时执行；退出或休眠后保存状态，重新启动时恢复符合条件的任务。没有安装系统常驻服务。
- 工程报告属于可审阅草稿，缺少阈值、规范或项目条件时需补充资料；AI 检查不替代专业审定。
- v0.5.4 历史资产保留原名称，不覆盖历史下载文件。
