## 重跑与独立性

```sh
python3 docs/qa/release-gates/v0.5.3/independent-numerical-expectations-20261008.py
```

同目录 `.py` 是独立 QA 脚本，`.json` 是完整机器可读输出。运行环境 Python 3.12.7 / NumPy 2.4.6。IN2 直接按 CSV 与 Decimal 紧凑 `D.MMSS` 解析，以两圆交点建立初始坐标，使用方向、距离的解析导数、NumPy LAPACK 最小二乘与 SVD 求协方差。解析导数与中央差分最大差 `1.93e-11`；四种局部初值最终坐标最大差 `8.53e-14 m`，方向差 `2.23e-16 rad`。非法分/秒 60 被拒绝。

## GSI：BM=100 m 的 600 m 闭合水准路线

该固定样例单位码 8 表示 `0.00001 m`。WI83..58 提供起点累计高程 100 m；后续 WI83..28 累计高程为 99.8 / 100.6 / 99.8001 / 100.0004 m。累计距离为 100 / 300 / 500 / 600 m，必须取相邻差形成 100 / 200 / 200 / 100 m 路线段。Z01/Z02 为块内转点，预期保留为 `gsi-block-1:Z01`、`gsi-block-1:Z02`。

相对定权明确为 `Pii=L0/Li`，`L0=1 m`；数值等价于 `1/L_numeric_metres`。没有声明每条观测绝对 σ，所以不能从该权阵推导真实先验绝对精度。该规范化下 Q 无量纲，单位权标准差为 m，平方因子为 m²；若把 `1/L` 当有量纲逆长度，则单位权尺度相应变化。共同权常数 C 改变时 Q 与方差因子反向缩放，后验坐标协方差保持不变。用户界面与成果须说明相对定权及其规范化，不能套用绝对 σ 定权的无量纲方差比解释，也不能表示已校准的仪器先验精度。

这些是**数值实现比较阈值**，不是工程规范限差；在读取本轮安装包数值之前声明。机器可读实际记录以全精度比较，界面/导出显示还需考虑明确的舍入精度，不可用粗显示值比较微小残差。
