# Ego 浏览器与订阅列表汇总

本次增加现有 RailWise AI Runtime 内的任务级 Ego 只读接入，不增加第二套智能体 Runtime。新任务明确指定 Ego 浏览器时，使用 Ego 工具；已有 BrowserSkill 任务、连接设置、Skill、凭据引用和历史成果继续保留，不自动更换执行后端。

Ego 的 Skill 文件、外置 CLI 可用、网站已登录和任务读取成功是不同状态。应用检查外置 CLI 的版本及文件身份；只有本任务实际打开并读取页面后，才有浏览器读取证据。应用不会复制 Cookie、导出浏览器配置、自动更新 Ego 或接管用户正在操作的页面。CLI 缺失、版本不兼容或用户接管时，需要处理对应连接问题，再明确继续原任务。

用户明确要求汇总订阅列表时，新任务可以按实际读取的列表验收。报告标注“列表数据／正文未核验”，保留已看到的来源和条目链接；预算、截止时间、资格条件等缺失字段保持待核验。列表条目不能代替官方正文核验。已有要求读取公告正文的任务继续使用原验收要求，不自动降级。

读取只覆盖任务授权的站点和实际访问的页面。分页未结束、页面仍在加载、达到页数上限或没有可用的下一页入口时，报告说明覆盖范围，不声明已读取当天全部更新。既有订阅关键词和业务表单不自动修改。

成功交付前，应用先核对成果和已要求的计划，再等待 Ego 结束本任务的浏览器空间。该步骤只执行一次，保留用户创建及来源不明的标签页；错误或用户接管时不自动清理。结果未知时保留原回执，不重复结束空间，也不将任务标为完成。

定时计划保留浏览器后端、站点和成果要求。更换来源需要新任务和对应授权；旧计划可在应用中暂停，原记录与历史版本保留。安装新版本不会将旧计划改成大单网计划。

兼容目标为 Ego CLI `0.6.3.14`，与独立版本的使用指南区分。实际 SDK、网站登录、生成成果和计划到期执行的结果须以最终精确安装包的验收记录为准；离线协议测试不代表这些步骤已经通过。


外置 Ego CLI 的版本及 SDK 结果可能写入 stderr。应用对固定版本探针兼容两个输出通道，并只接受一次符合协议的 SDK 结果，不将普通诊断当作网页证据。此前停在版本预检的任务保留原记录；安装修复包后重新检查连接，再明确继续原任务，无需重装 Ego、清除配置或重新提交请求。

页面读取使用标准 CSS 选择器，并关联最近一次观察。选择器无效、匹配数量不符、内容不可见或不支持读取时，工具返回明确的可修正结果，让任务重新观察和选取；这些情况不再统一显示为连接故障。未知读取异常、协议不符、授权到期和用户接管仍停止执行，保留诊断阶段及原记录。更新不会重置任务次数、预算或未知执行记录，也不会自动恢复暂停的任务。

原浏览器任务空间已经关闭时，需要区分空间缺失与用户正在接管。按照当前 Ego 指南，同一目标在明确继续后可以重开已关闭的空间；应用须自行核实旧 ID 与原唯一名称均不存在，再使用新服务端标识建立一次接续。旧空间回执、来源、失败与已用预算保留，不通过覆盖旧绑定或创建无关联任务重置执行。空间仍存在但控制权不明、查询失败或创建结果未知时，继续等待核验。本项以对应精确包的恢复验收结果为准，实施中的代码不代表实际任务已通过。

动态订阅列表的历史快照继续保留，恢复后的本轮报告需要先通过原授权浏览器实际读取当前列表。回看旧来源、旧报告或任务上下文不会被当作新采集；当前采集日期与列表公告日期分别说明。同一轮重复读取相同内容不会清空仍未解决的核验问题，任务总次数、费用和执行时间记录继续保留。

这项本轮读取要求限定于明确的订阅列表汇总。普通历史公告正文与本地 HTML／SVG 制作继续沿用各自合同。用户无需复制页面、重新填写供应商 Key 或删除旧任务；实现和最终精确包的真实结果见对应验收记录。

结构化订阅报告会统一展示输入中的完整项目名称并生成待核验声明。此步骤不认定来源真实，也不代填预算、截止时间或资格条款；不符合当前实际记录的标题仍不能通过核验。旧报告与原始依据保留。


升级后，系统会依据已保存的真实完成证据，将已完成任务对应的旧网页核验提醒标为已处理，并保留原诊断及解决依据。未完成、未核验和其它权限或审批提醒继续按原状态处理；这项补偿不重新执行任务，也不改变原操作、授权或预算。选中原任务即可查看其成果，任务工作台会跟随该任务的新成果打开预览；关闭过的同一版本继续保持关闭，新版本另行打开。
