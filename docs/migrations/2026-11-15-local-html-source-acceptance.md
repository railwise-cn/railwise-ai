# 本地 HTML 创作任务的来源验收纠正

旧版把请求中的“浏览器”直接视为网页采集要求。因此，“创建独立 HTML/SVG 动画，打开浏览器查看”可能在文件已生成、预览正常后，仍因缺少网页来源而停滞；执行、验证、交付节点也可能全部显示失败。

新任务使用同一份版本化来源意图规则。本地创作和浏览器查看不要求外部正文证据；明确抓取、查询、读取外部网页后再生成 HTML/SVG 的混合任务继续执行来源验收。显式使用 BrowserSkill 仍检查该工具的连接和权限。

旧任务、工作区、成果文件、写入回执、执行账本和费用记录均保留。正在执行的任务不会被迁移或中断，也不会因为文件存在而自动标记完成。

仅要求 HTML/HTM 的受影响停止任务可以通过“重新检查成果”明确触发重验；HTML 加 PDF 等混合格式不在此修复范围。后端核对旧误分类合同、停止状态及版本，重新读取文件并核对原成功写入回执、哈希、格式、最少文件数、明确文件名、可用成果卡和交付回复。只有检查通过才可完成；文件改变、缺回执、缺有效回复或仍有未知操作时保留待办，不重放动作或自动调用模型。重验以幂等键记录旧合同、原节点状态和新检查证据，不重置尝试次数、时间或费用。

有效文件写入后，执行节点单独记录完成。后续来源或成果核验阻断不会抹去该执行证据，验证和交付显示各自状态。

重验确认的范围是 HTML 结构、已保存文件、授权写入回执、哈希及可用交付卡的一致性。它不代表动画造型、运动效果或画质已经通过人工审阅，也不构成工程计算、专业审定或规范符合性认可。
