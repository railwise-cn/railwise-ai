# 一次性公开查询失去会话后的新范围确认

旧的一次性浏览器授权只用于原任务。会话已失效且原操作仍未知时，系统不会把它当作“未执行”，也不会重派旧操作、复用旧会话或延长已到期授权。原任务、未知回执、预算账本、成果文件、历史审批均保留。

本次新增的入口只适用于已有可信有限公开查询记录、且实际核验得到会话不存在的一次性任务。用户先审阅当前目的、浏览器、站点和最长 15 分钟有效期并重新勾选，再单独点击继续。准备范围不会创建执行回合、调用模型或打开浏览器。继续产生同一任务历史中的重试记录、新任务自己的浏览器范围和短期执行授权。

范围有效期按服务器确认时刻固定计算。重复请求、暂停或重启不会延长；到期或撤销后须重新审阅。原任务的临时文件/网络权限不会作为新任务授权沿用；若需要临时权限，新任务使用自己的权限卡确认。当前工作区、Agent、浏览器连接、站点或能力配置变化时，必须重新核对范围。

持续计划仍使用原有计划恢复合同，本次不修改已保存 Flow、授权封存或计划状态。提交、发送、账号操作、无法解释的未知副作用、任意 MCP/Shell 写入不适用此入口，仍须核验原结果。取消后不会自动恢复旧请求。

不删除或替换任何 Skill、插件、MCP 配置、凭据引用或用户数据。用户无需重装或手动修改历史记录；符合条件时，在原任务卡审阅新范围即可。旧 IPC 和旧计划数据继续兼容读取。

本变更的受控 Runtime 回归使用合成页面、协议适配夹具和本地模型响应，验证真实 Runtime/HTTP/SQLite/文件和授权链；它不代表公网采集任务已完成，也不代表供应商未知结果的起因已修复。新代码仍须在其对应精确包中完成实际验收。
