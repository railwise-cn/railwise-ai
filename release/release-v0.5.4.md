# RailWise AI 0.5.4

本次更新扩展本地写作、文档与演示工作流，并完善插件和 Skills 的发现与安装体验。

在侧栏打开“写作”，即可管理多个 Markdown 文档、搜索正文、编辑文档属性、查看链接、历史与本地批注。可视化、源码和分栏模式共享文件内容；数学公式、脚注与 Mermaid 图表支持本地预览，点击“编辑源码”可修改并实时核对效果，随后导出 HTML、PDF 或 DOCX。

选中文字后可请求改写、压缩或扩写，AI 先展示差异，确认后才应用。关闭自动写作建议仍可手动请求；外部内容或选区发生变化时，旧提案会被阻止写入。文件修订冲突、只读大文件和本地快照帮助保留正在编辑的内容。

设计区导入 PPTX 后可在编辑、参考与对比模式之间切换。原稿、母版、主题、布局和复杂对象保持保留，支持的对象修改以修订保存；工具栏和侧栏随浅色/深色主题切换。复杂动画、图表及特定 PowerPoint 对象的最终效果仍应在原生应用中复核。

“插件”与“工具”保持独立入口。插件市场提供精选工作流，Skills 概览显示可见的推荐项，并说明用途与使用方法；完善 GitHub 下载、归档内部链接和本地索引的处理，同时保留路径越界保护。

默认模型与自动模式统一使用 DeepSeek V4.1 Flash（`deepseek-flash`）。已有明确保存的模型、供应商、地址和凭据引用保持不变。已有工作区、插件、MCP、Skill、会话与工程资料继续保留。

同步更新文档解析、MCP 和网络请求依赖的安全补丁，并改进离线图表资源的构建与校验。

公式、图表与导出默认在本机处理。DOCX 为支持的数学结构生成可编辑 Office Math，对复杂公式布局使用本地图片；原始 Markdown 继续作为权威内容。文档与 AI 结果中的事实、数字、单位及正式版式仍需结合使用场景审阅。
