# RailWise AI 0.5.6

本版完善持续任务、连接器授权、工程文档交付和应用升级。

## 持续任务与可信执行

- 用户围绕目标、进度、待办和成果管理任务。内部执行会话归并到根任务，技术信息可在诊断中查看。
- 状态询问读取本地进度。补充要求持久入队，暂停期间保留输入，新任务使用独立执行上下文。
- 权限卡显示当前任务的工具、路径、网络和平台范围。外部写入使用明确目标、操作确认、持久回执与结果核验。
- 组合任务逐项核验成果，部分完成时继续显示剩余事项。重试保留原目标、验收要求与授权记录，结果不明的操作进入核验流程。

## 连接器与工程资源

- 飞书与钉钉分别提供官方连接和授权流程，支持待办查询与完成、审批详情、同意和拒绝。飞书增加消息发送和云盘上传的确认与回读。
- 修复 GitHub MCP 的连接配置，提供受保护令牌存储与真实工具发现。高德地图提供地点、路线和天气等只读工具，Zotero 提供本机文献、集合、全文及引用读取。
- 改进 macOS 受保护凭据读取，界面在系统确认期间保持响应，同一次运行复用已成功读取的凭据。凭据变更、删除或停用后核对新的有效状态。
- 页签顺序调整为“技能、插件、连接器”，默认展示技能。新增资料盘点、监测质检与图表、文档差异审阅、会议纪要与待办四项工程技能。
- 市场提供 AutoCAD DWG 重绘及图片转 CAD 两项固定上游技能。DWG 流程需要 Windows 和 AutoCAD，macOS/Linux 可使用粗略 DXF 流程。
- 随包目录、缓存和固定版本资源支持市场浏览与安装状态反馈。工程报告、投标文件和研究报告采用 AI 辅助工作流，成果附来源、验证结果和待确认项。

## 升级与帮助

- 有更新时，左下角显示紧凑的“升级”入口。一次点击完成下载校验、内容保存、安全停止、安装与重启，失败时提供具体原因和重试入口。
- 帮助中心内置完整 13 章中文手册，支持离线阅读、全文搜索、章节目录及内部链接。帮助入口和系统菜单已移除个人主页。
- 升级保存任务、输入、草稿、历史资料及配置引用。已完成正式 0.5.4 到本版精确安装包的原生升级验证。

## 安装包验证

macOS 安装包已通过 Developer ID 签名及公证。Windows 安装器和应用的 Authenticode 状态为 `NotSigned`。

本版精确包完成 Windows 中文界面检查、macOS 实机连接验收、任务恢复回放及原生升级测试。实际制品摘要与源码对应关系记录在发行验收清单中。
