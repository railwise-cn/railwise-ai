# RailWise AI 0.5.7

本版改进桌面工作台、任务授权和恢复、浏览器采集、文件交付及周期计划。[精确制品与验收记录](https://github.com/railwise-cn/railwise-ai/blob/v0.5.7/docs/qa/release-gates/v0.5.7.json)

## 浏览器与技能

- BrowserSkill 接入受管理 CLI、官方 Chrome/Edge 扩展和浏览器实例选择，详情显示依赖、连接、协议兼容性与站点范围。
- 技能安装、启用、停用和更新同步到当前运行的任务服务，保留原有技能资料与配置。
- 缺少能力的请求保留原任务与待办。连接完成后核对任务范围，确认与继续执行分别操作。
- 浏览器操作使用任务内的页面上下文。相同有效配置的诊断刷新复用执行实例，真实配置变化需要重新核对授权。
- 公开采集使用经任务明确确认的查询范围，搜索、阅读和翻页绑定原目标与输入；业务操作保持严格校验。旧许可不会自动改变策略。
- 同站公告详情链接经真实节点、地址及页面身份核对后，以只读导航打开，不运行该链接的业务点击脚本。没有有效地址、下载、跨站或权限变化仍保留具体处理入口。
- 页面上下文变化时，仅对官方明确确认未执行的动作尝试一次有限恢复；动作已确认后的回读失败单独记录，完成前核对原页面，不重复输入。
- 长网页进入模型上下文时按原顺序保留有效文字与链接，不再套用终端日志的头尾抽样。内容超限时明确标注，并通过原任务的上下文分段读取。
- RailWise 可通过 Ego 在每轮任务中创建自己的 Space，沿用已登录的浏览器状态访问授权站点，完成后关闭该任务的 Space。已在 macOS 上实测大单网订阅读取、生成报告与计划到期执行。
- 插件能力变化时按需刷新，MCP 配置应用后回读运行时确认。

## 文件交付与预览

- HTML 报告登记为实际任务成果，当前会话的首个可预览 HTML 自动打开右侧预览。任务中心查看成果或主动关闭后，可从成果卡重新打开，检查正文、来源和保存位置。
- 只读工作区可把新报告保存到应用任务成果目录。指定项目目录的写入按具体路径申请权限。
- 文件更新、来源缺失、权限阻断和结果待核实状态保留在任务记录中，完成状态关联实际成果与执行证据。
- 网页报告分别显示文件检查和来源核验状态。正式条目关联实际读取的正文、原文入口和字段依据，各必需来源分别核查；只有列表或搜索入口的旧报告保留为草稿，不按正式成果完成。
- 草稿仍可预览，来源状态绑定实际打开的文件版本。旧草稿不会借后来文件的证明显示已核验，也不会发送已核验成果通知。
- 文件成功写入并保存回执后及时更新草稿预览，无须等模型结束整项任务。暂停、失租、失败或结果未知的写入不能登记为新成果。
- 原创独立 HTML 或 SVG 动画按本地文件验收。旧任务可显式重验已保存的文件，修正来源要求误判。
- 大单网订阅汇总说明实际读取范围，按相关、待判断和排除展示 AI 筛选依据，保留可见列表字段和打印样式。列表来源可单独核验，公告正文以实际读取结果为准。
- 后台任务完成后，正在查看的预览会保留。点击对应任务的成果即可切换。

## 每日计划与执行范围

- 对话任务支持每日多个时刻和明确时区，保存后读回执行时刻、时区与下一次运行时间。
- 交付时间可结合提前量换算为启动时间。中文请求默认时区为 `Asia/Shanghai`，“某时刻前”且未给提前量时采用提前 30 分钟启动。
- 周期网页查询的填写与点击采用经过审阅的有限持续范围，绑定站点、目标、输入和浏览器实例。计划停用、授权撤销或范围变化后停止后续派发并显示待办。
- 每次周期执行保留自己的任务和成果记录。结果待核实的动作进入核验流程。
- 排队准备期间保留任务的执行归属，避免恢复器抢先启动另一轮；旧执行结束时只清理自己的运行记录。
- 重复观察被拦截后，模型先在当前回合读取拒绝结果并尝试使用已有来源继续交付；持续重复会明确停止，不再反复触发空成果验收。
- 浏览器重新绑定后，已完成并核验的历史动作保留审计记录，不要求在新计划中重做；未结、未知及待回读动作仍阻止派发。
- 修正计划保存后继续查询时，当前尚未派发的调用被误判为旧未结操作的问题；其他在途或未知操作仍需核验。
- 已批准的有限公开查询在结果未知时可只读检查原网页，经人工确认后保存独立依据；原记录保留，任务由用户单独继续，不自动重放原动作。
- Flow 按顺序完成保存和发布，回读服务端状态。调整流程画布布局时保留当前流程版本。

## 日常界面

- 简短进度、待办、审批和成果集中呈现，详细参数与长输出保留在可展开的工作详情中。
- 浏览器审批显示业务目标与输入，技术指纹位于执行详情。
- 等待审批的紧凑进度与列表只显示简短提示，原始审批参数与技术摘要不进入默认进展文案。
- 已处理的历史能力卡保留摘要与配置入口，当前授权事项通过任务中心处理。
- 文件成果显示文件与来源核验状态，外部操作另列回执，不再因外部回执为空而误称整个文件任务未执行；内部路径、工具名与哈希放入执行详情。
- 左侧任务列表按当前执行分支的最新更新时间排列；实时更新不会把新任务沉到列表底部，历史失败记录仍保留查看入口。
- 任务搜索和状态筛选并入左侧栏，中央显示所选任务。可展开原始要求、权限和执行详情。
- 窄窗口下导航和成果区可切换为抽屉，保留已打开成果和宽度偏好。General、模型、执行方式选择菜单随可用空间定位，技能、文件和命令建议可在较矮窗口内滚动。设置导航和离线帮助目录也随空间调整。
- 审批决定在界面显示简短状态。执行时长预算按实际执行用时计算，报告内的文件入口指向对应任务工作区。

## 升级、退出和平台验收

- 左下角的“升级”入口自 0.5.6 提供。检测到更高版本时显示，可以在通用设置手动查看更新状态。0.5.7 尚未提供升级完成后的工作台首页“本版更新”提示。
- 退出应用时先等待正在收尾的执行服务停止。系统未能确认停止时，应用会给出提示并留在当前窗口，以便继续保存或稍后退出。
- Apple Silicon Mac 已验证精确安装包的原生界面和 0.5.6 升至 0.5.7。General 菜单和工作区导航验收覆盖 1280×840 与 960×760。
- Windows x64 已验证安装和受控 BrowserSkill 任务回归，安装器与应用的 Authenticode 状态为 `NotSigned`。
- 有 Windows 用户在下载 0.5.7 后反馈，点击“重启安装”无反应，重启后版本仍未变化。现有 Windows 安装验收覆盖全新安装，原位升级问题仍在排查。
