# RailWise AI 0.5.7

本版完善浏览器技能、真实网页成果与周期任务的执行链。精确制品及实际验证范围见[验收记录](../docs/qa/general-execution-delivery-2026-11-13.md)。

## 浏览器与技能

- BrowserSkill 接入受管理 CLI、官方 Chrome/Edge 扩展和浏览器实例选择，详情显示依赖、连接、协议兼容性与站点范围。
- 技能安装、启用、停用和更新同步到当前运行的任务服务，保留原有技能资料与配置。
- 缺少能力的请求保留原任务与待办。连接完成后核对任务范围，确认与继续执行分别操作。
- 浏览器操作使用任务内的页面上下文。相同有效配置的诊断刷新复用执行实例，真实配置变化需要重新核对授权。
- 页面上下文变化时，仅对官方明确确认未执行的动作尝试一次有限恢复；动作已确认后的回读失败单独记录，完成前核对原页面，不重复输入。

## 文件交付与预览

- HTML 报告登记为实际任务成果，当前会话的首个已核验 HTML 自动打开右侧预览。任务中心查看成果或主动关闭后，可从成果卡重新打开，检查正文、来源和保存位置。
- 只读工作区可把新报告保存到应用任务成果目录。指定项目目录的写入按具体路径申请权限。
- 文件更新、来源缺失、权限阻断和结果待核实状态保留在任务记录中，完成状态关联实际成果与执行证据。

## 每日计划与执行范围

- 对话任务支持每日多个时刻和明确时区，保存后读回执行时刻、时区与下一次运行时间。
- 交付时间可结合提前量换算为启动时间。中文请求默认时区为 `Asia/Shanghai`，“某时刻前”且未给提前量时采用提前 30 分钟启动。
- 周期网页查询的填写与点击采用经过审阅的有限持续范围，绑定站点、目标、输入和浏览器实例。计划停用、授权撤销或范围变化后停止后续派发并显示待办。
- 每次周期执行保留自己的任务和成果记录。结果待核实的动作进入核验流程。
- 已批准的有限公开查询在结果未知时可只读检查原网页，经人工确认后保存独立依据；原记录保留，任务由用户单独继续，不自动重放原动作。

## 日常界面

- 简短进度、待办、审批和成果集中呈现，详细参数与长输出保留在可展开的工作详情中。
- 浏览器审批显示业务目标与输入，技术指纹位于执行详情。
- 等待审批的紧凑进度与列表只显示简短提示，原始审批参数与技术摘要不进入默认进展文案。
- 已处理的历史能力卡保留摘要与配置入口，当前授权事项通过任务中心处理。
