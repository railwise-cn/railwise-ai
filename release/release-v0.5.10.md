# RailWise AI 0.5.10

## 在原对话完成任务

侧栏以会话为入口。任务的进度、审批、补资料提示、继续、暂停和成果都显示在原对话正文里，跟随消息滚动。前台和后台执行记录的步骤都可在正文内展开。此前的任务链接也打开对应原会话。授权先说明操作和范围，原始命令、回执和重试记录可按需展开。

有一项开放式问题等待答复时，可以直接在输入框回复。批准后，原任务继续执行。即使任务服务曾重启，只要能确认原操作尚未执行、授权范围仍适用，也会恢复同一任务。已暂停、取消或失效的授权请求不能启动旧操作。完全相同的已执行命令可复用原回执，避免重复弹窗和执行。任务的最终答复保存在原对话中，定时运行也将实际结果交回原对话。

因任务审批策略受阻时，可在原对话审阅范围，然后选择「授权并继续」。应用会核对新授权和原待处理事项，再续接当前任务。如果任务或权限范围在确认期间发生变化，对话正文会提示重新核对。

修复「先输出进展」等普通说明触发文件写入权限提醒的问题。大单网要求重新登录时，原对话提供「登录后继续」，继续时优先读取本任务原有的 Ego 空间。

## 聊天附件、技能和界面

使用 `/`、`/skills` 或「＋ → 技能」可以搜索当前会话可调用的技能。选中后显示可移除的名称标签。附件在输入区用紧凑卡片呈现，保留扩展名和单项重试入口，更多附件按需展开。Windows 和 macOS 随包使用同源 Noto Sans SC，输入区和菜单按实际可用宽度调整。

切换工作区会刷新可用技能。已选技能失效时，标签下提示移除或重新选择，并保留草稿和附件。「＋」菜单按 Esc 后回到消息输入框。连接本机助手时，界面显示简短的连接状态和重试入口。

Superpowers 提供经校验的内置安装包，Blender Skills 通过睿威镜像安装。两者在市场中可查看具体子技能。在现有安装基础上更新时，保留安装范围、设置和授权记录。

## 模型与资料

模型回复中断时，部分回复保留在原会话，可以从会话内原有进度继续。制作视频等任务可以查询和读取已授权的 PDF 章节，续接时保留原附件。中文 PDF 的文字恢复使用随包资源。导入时原文件暂时找不到，文件恢复后可在原草稿中重试。已授权的渲染完成后，KUN 使用核对过的命令回执登记本次生成的成片。

修复短扫描 PDF 的跨页引用，配置 OCR 后可按原页码检索识别文字。

计划页面应用最新的保存结果，并按指定时区显示运行时间。暂停计划会阻止还未开始的运行。单项修改保留其他计划及既有运行记录，已过期的单次计划继续按原规则校验。

## 升级与恢复

Mac 安装更新时会完整退出应用。安装中止后，应用会在确认本地任务服务安全停稳后恢复工作，并将失败阶段和原因记录到本机日志。已校验的安装包可用于重试。
