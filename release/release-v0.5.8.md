# RailWise AI 0.5.8

## 表格与会话

- 新建和编辑本地表格，使用多工作表、公式、撤销和 CSV 导入导出。`.rwsheet` 文件可保存后重新打开。
- 在工作区及任务成果中查看常见 Excel 工作簿。复杂工作簿可在系统应用中打开，原文件按原格式保留。
- 聊天框输入 `/`，即可搜索并选择当前工作区可调用的技能。选中后继续输入要求，发送时核对技能是否仍可用。
- 会话和任务详情显示实时进度、审批与成果。执行命令、错误输出和重试记录可展开查看。

## 市场与桌面升级

- 官方市场可镜像的包及安装依赖使用睿威下载源，按版本和平台校验。受许可证限制和需要账号的项目在详情中显示相应要求。更新保留现有插件、权限和连接配置。
- Filesystem MCP、Memory MCP 和 Sequential Thinking MCP 补充上游的完整许可证及署名说明。已安装版本、启用状态和权限记录保留。Redis MCP 的镜像包附带对应版本的 MIT 许可证。
- Video Shotcraft 的睿威镜像使用独立分发版本，保留锁定上游提交中的 Apache-2.0 代码、文档和署名记录。成片制作使用自有或已许可的素材，并另备 Node.js、npm、适用许可的 Remotion、受支持的 Chromium 与 FFmpeg / FFprobe。已安装的旧版及其配置会保留，可在市场查看新版要求并选择更新。
- 发现新版时，工作台左下角显示升级入口，升级后在首页可查看本版更新。Windows 安装前会先等待本地执行服务保存并退出。
- Windows 旧版的重启安装未完成时，可从睿威官网下载对应安装器并覆盖安装。安装后核对应用版本及原有工作区。

## 发版验收

发布前记录三种安装包的确切版本、摘要及平台签名状态。验收应包含官网镜像冷缓存安装、普通会话调用 Video Shotcraft 后播放成片、Playwright MCP 浏览器操作、Docling 启动、断网表格、任务状态及旧版原位升级。发布页面将使用验收通过的安装包和更新说明。
