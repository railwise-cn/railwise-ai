# 资料盘点与来源索引

先读取用户指定的目录、附件和资料清单。根据实际可用工具访问资料，`read_delivery_sources` 可将工作区正文及指纹纳入任务来源。

来源表记录相对路径、标题、文件版本或日期、可核验定位、指纹、适用章节和缺失项。同名文件按内容指纹区分。扫描件注明 OCR 解析情况。关联来源采用实际读取结果，找不到的页码或版本保持待确认。

用户要求报告时，可用 `propose_document` 创建候选索引，并关联本轮读取的 `source_refs`。先交付索引、缺项和冲突，再按用户要求处理正文。资料原件保留。

## 合成样例

读取 `samples/brief.md` 与 `samples/list.json`，依照 `samples/case.json` 验收。样例中阈值资料缺失，应记录一项待确认，不能补造规范阈值。
