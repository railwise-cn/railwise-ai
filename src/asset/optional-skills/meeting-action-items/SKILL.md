# 会议纪要与待办

以用户提供的会议记录为依据，保留会议日期、议题、决议、发言依据和行动项。每项待办引用记录中的段落、时间戳或页码。

仅将明确同意的事项写为决议。责任人或截止时间缺失时留空并列入待确认。相对日期按已知会议日期换算，时区和日期不明确时保留原始说法。

先交付可审阅纪要与待办表。用户要求写入钉钉或飞书时，根据真实连接器与当前任务授权执行，明确平台、目标和动作，完成状态引用对应操作回执。只生成纪要时，以实际候选文件和来源作为交付证据。

## 合成样例

读取 `samples/transcript.md`，按 `samples/case.json` 验收。两项待办中一项没有责任人，应保持待确认。样例不授权向任何外部平台发送内容。
