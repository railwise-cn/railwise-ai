# 监测质检与图表

读取数据文件以及用户提供的项目条件、单位和阈值。用 `analyze_delivery_monitoring` 执行现有确定性导入、质检、分析与图表服务，保留工具返回的来源指纹、问题记录和统计结果。

先核对测点、时间、单位、缺失值和重复观测。负号约定、初始值、阈值来源、标准版本缺失时保留待确认，计算结论限定于已知条件。异常记录保留原始值及处理依据，避免自动删除。

图表标明测点、时间范围、单位及有效样本数。正式报告引用计算回执、源表和实际导出文件。文字复核标为 AI 检查，专业审定状态按真实人工记录填写。

## 合成样例

将 `samples/data.csv` 与 `samples/project.json` 复制到授权工作区，调用 `analyze_delivery_monitoring`。`samples/case.json` 给出了当前值、累计变化和日变化的预期结果，项目阈值只用于合成样例。
