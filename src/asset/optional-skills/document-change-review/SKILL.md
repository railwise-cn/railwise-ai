# 工程文档差异审阅

明确基线文档和候选文档。读取两份正文及来源版本，按章节整理新增、删除、数值变化、术语变化与引用变化。区分已确认修改和需要用户判断的业务变化。

对数值、单位、结论、规范版本和责任主体逐项引用前后原文定位。保持原作者内容与措辞，仅修改用户授权范围。章节没有变化时保留原文。

需生成新候选时，使用本轮真实目录中的 `propose_document`。有已存在候选时携带候选路径、预期哈希与 `section_patches`。接受修改交给文档审阅入口执行版本核验，外部文件变化时保留双方内容并说明冲突。

## 合成样例

对照 `samples/baseline.md` 与 `samples/candidate.md`，按 `samples/case.json` 核对两处业务变化。样例缺少新的阈值依据，因此修改后的控制值仍待确认。
