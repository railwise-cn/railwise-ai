# Humanizer-zh · RailWise 内置版

编辑已有中文文本中的空话、重复和模板化表达，保留事实、确定程度、作者声音与文件结构。不判断作者身份，也不保证通过 AI 检测器。

在当前对话的技能列表中选择 Humanizer Zh，或点名使用 `humanizer-zh`，再提供要编辑的文字或文件。只要求审阅时不会写回文件。

本版运行规则来自官方提交 [`f4518a8eab97b8bfebc66a89d34320a89bef6930`](https://github.com/op7418/Humanizer-zh/tree/f4518a8eab97b8bfebc66a89d34320a89bef6930)（2026-09-23），无官方版本标签。随包保留 [MIT License](LICENSE)，来源与兼容说明见 [上游记录](references/upstream.md)。

RailWise 随安装包提供规则，不要求运行外部安装命令；第三方自动更新关闭。官方使用说明和测试材料见 [上游 README](https://github.com/op7418/Humanizer-zh/tree/f4518a8eab97b8bfebc66a89d34320a89bef6930/README.md) 与 [测试说明](https://github.com/op7418/Humanizer-zh/tree/f4518a8eab97b8bfebc66a89d34320a89bef6930/tests/README.md)。上游测试结果属于上游记录，不作为 RailWise 真实模型验收结果。
