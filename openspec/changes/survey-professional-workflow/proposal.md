## Why

The simplified Survey UI hides essential engineering checks, while exported reports mostly contain text and internal evidence sheets. Public COSA and SurveyCloud workflows show that engineers need traceable observations, reference controls, closure checks, precision tables and a coherent professional deliverable before AI efficiency can be assessed.

## What Changes

- Add a deterministic professional review projection without rewriting stored results or hashes.
- Keep reference controls, network/route checks, residuals and task-specific result tables accessible in the normal workflow.
- Render professional DOCX/PDF/XLSX tables from one frozen model, retaining existing machine-readable evidence and historical readers.
- Extend precise AI evidence tools with professional checks and explicit unavailable states.
- Implement controlled open-table mapping and multi-period comparison where supported by verifiable source contracts.
- Record staged numerical, artifact and packaged-application acceptance, with external interoperability and professional signoff tracked separately.

## Capabilities

### New Capabilities

- `survey-professional-review`: Source-bound professional interpretation, task workflows and precise evidence retrieval.
- `survey-professional-deliverables`: Professional report tables, diagrams and consistent printable outputs.
- `survey-confirmed-table-import`: Explicit, preserved table mappings with units, datum and source provenance.

### Modified Capabilities

None. Existing release and migration gates continue to apply.

## Impact

Survey contracts/services/routes, engineering evidence tools, renderer Survey panels, runtime request allowlists and report renderers. Existing calculations, files, plugins and configuration remain compatible. Public release operations require separate exact-version approval and packaged acceptance under AGENTS.md.
